# Как собрать .EXE из ASM Workshop

Инструкция для **Windows**. Цель — получить `ASMWorkshop.exe`, который запускается
двойным щелчком без установленного Python.

---

## Шаг 0. Что нужно установить

1. **Python 3.10+** — <https://www.python.org/downloads/>
   ⚠ При установке обязательно поставьте галочку **«Add python.exe to PATH»**.
2. **NASM** (обязательно, иначе ассемблирование не работает) — <https://www.nasm.us/pub/nasm/releasebuilds/>
   Скачайте `nasm-xxxx-x64.zip`, распакуйте, например в `C:\nasm`, и добавьте эту папку в **PATH**:
   *Параметры системы → Переменные среды → Изменить PATH → Добавить `C:\nasm`*.
3. *(необязательно)* **binutils / objdump** для деассемблирования через внешний движок.
   Если его нет — программа автоматически использует встроенную базу кодов.

Проверка в командной строке (`cmd`):

```bat
python --version
nasm -v
```

Обе команды должны показать версию.

---

## Шаг 1. Подготовить проект

Скопируйте `asm_workshop.py` в отдельную папку, например `C:\asmworkshop`, и откройте её
в проводнике. В адресной строке проводника введите `cmd` — откроется консоль в этой папке.

## Шаг 2. Установить PyInstaller

```bat
pip install pyinstaller
```

## Шаг 3. Собрать EXE

Однофайловое приложение с иконкой и без консоли (веб-интерфейс открывается в браузере сам):

```bat
pyinstaller --onefile --noconsole --name ASMWorkshop asm_workshop.py
```

Если нужен режим `--gui` (нативное окно CustomTkinter), добавьте библиотеку и скрытый импорт:

```bat
pip install customtkinter
pyinstaller --onefile --noconsole --name ASMWorkshop --collect-all customtkinter asm_workshop.py
```

Готовый файл появится здесь: **`dist\ASMWorkshop.exe`**

### Полезные флажки

| Флаг | Зачем |
|---|---|
| `--onefile` | всё в один .exe |
| `--onedir` | папка с .exe + зависимостями (запускается быстрее) |
| `--noconsole` | не показывать чёрное окно терминала (для режима `--web`) |
| `--console` | оставить окно терминала (нужно для режима `--cli`) |
| `--icon app.ico` | своя иконка (файл формата `.ico`) |
| `--add-data "файл;."` | приложить дополнительный файл к сборке |

### Сделать, чтобы двойной щелчок сразу открывал веб-интерфейс

По умолчанию скрипт и так стартует в режиме `--web`. Чтобы запустить CLI-версию:

```bat
pyinstaller --onefile --console --name ASMWorkshop-CLI asm_workshop.py
```

и создайте рядом файл `start.bat`: `ASMWorkshop-CLI.exe --cli`

## Шаг 4. Проверить

Запустите `dist\ASMWorkshop.exe` — должен открыться браузер с интерфейсом.
Проверьте: кнопка **«ℹ О программе»** работает, таблицы формируются, NASM вызывается
(если пишет «NASM не найден в PATH» — см. шаг 0, п. 2).

---

## Частые проблемы

- **«'python' is not recognized»** — не поставлена галочка Add to PATH при установке Python.
  Переустановите или пропишите `C:\Users\<вы>\AppData\Local\Programs\Python\Python312\` в PATH.
- **«NASM не найден в PATH»** — папка с `nasm.exe` не добавлена в PATH (шаг 0, п. 2).
  Антивирус иногда блокирует запуск nasm из временных папок — добавьте папку проекта в исключения.
- **SmartScreen «Неизвестный издатель»** при первом запуске self-contained .exe — это нормально
  для неподписанных сборок; нажмите «Дополнительно → Выполнить в любом случае».
- **Большой размер .exe (~10–30 МБ)** — нормально: в one-file упакован интерпретатор Python.
- **Файл не запускается на другом ПК** — убедитесь, что собираете на Windows той же разрядности (x64).

## Автозапуск сервера при старте EXE (по желанию)

В `asm_workshop.py` в функции `main()` можно заменить ветку `else:` на явный вызов
`serve_web(port=8000)` — тогда адрес всегда будет `http://127.0.0.1:8000/`
и его удобно открыть в закладках.
